# 1835_ze_ju_we_ti

A complete browser-based form to run and record a full **1835** game from setup to final scoring.

## Usage

1. Open `/tmp/workspace/hm-lucx/1835_ze_ju_we_ti/index.html` in a browser.
2. Fill in game details, players, corporations, and optional round logs.
3. Use **Calculate Winner** to compute final standings from player cash + shares + privates.
4. Use **Save** to persist locally, **Export JSON** to download a snapshot, and **Import JSON** to restore a saved game.
5. Use **Reset Form** to start a new game.
